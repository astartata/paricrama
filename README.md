# Парикрама 2026 — офис

Веб-интерфейс для регистрации участников и администрирования размещения.

## Порталы

- `index.html` — административная панель: обзор, участники, размещение, настройки.
- `participant.html` — публичная форма регистрации.
- `cabinet.html` — личный кабинет участника для просмотра и редактирования заявки.

## Как работает заявка

- Участник заполняет форму в `participant.html`.
- При отправке создается запись в `registrations`.
- Выбранные места сохраняются в `placeLocks` как `occupied`.
- В `cabinet.html` участник может:
  - изменить данные участников;
  - добавить нового участника;
  - удалить участника;
  - убрать или добавить места;
  - сохранить изменения обратно в Firestore.

## Что нужно проверить вручную

1. Открыть `participant.html` и отправить тестовую заявку.
2. Убедиться, что после отправки создается аккаунт и открывается `cabinet.html`.
3. В кабинете изменить ФИО, email или телефон у участника и нажать `Сохранить изменения`.
4. Добавить нового участника через `+ Добавить участника`, затем сохранить.
5. Удалить одного участника и снова сохранить.
6. Удалить одно место и проверить, что оно освобождается.
7. Открыть `index.html` и убедиться, что админка видит обновленную заявку и места.

## Firebase

Проект использует:

- Authentication для входа;
- Firestore для `registrations`, `placeLocks`, `adminRooms`, `adminGuests`.

Если сохранение в кабинете не проходит, в первую очередь проверьте правила Firestore и права пользователя.
