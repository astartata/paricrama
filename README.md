# Парикрама 2026 — офис

Первая веб-версия интерфейса, восстановленная по книге Excel и серверной логике Google Apps Script.

## Два портала

- `index.html` — административная панель: обзор, участники, размещение, оплаты, дети, журнал и настройки текущей Парикрамы.
- `participant.html` — публичная форма регистрации: данные участника, семья/дети, тариф, пожелания по номеру и соседу.

Пожелание участника не является окончательной бронью: итоговое назначение номера выполняет администратор.

## Локальный просмотр

Откройте `index.html` в браузере или запустите любой статический сервер из этой папки.

## Модель Firebase

Год — отдельная сущность `events/{eventId}`. Внутри года: `hotels`, `rooms`, `tariffs`, `groups`, `registrations`, `payments`, `children`, `activityLog`. Один участник может создать группу и добавить в неё всех сопровождающих. Каждый человек хранится отдельной регистрацией, но имеет общий `groupId`; у заявки отдельно хранятся `preferredTariff`, `preferredRoom`, `roommate`, а в административной части — `assignedRoom`, `paymentStatus`, `checkInStatus`.

Публичный пользователь сможет создавать и редактировать только свою заявку через встроенную форму сайта и Firebase Authentication/ссылку на email. Анкета ребёнка будет отдельным встроенным разделом, связанным с заявкой родителя. Администраторские операции — назначение номера, подтверждение оплаты, заселение и настройка отелей — будут разрешены только аккаунтам с ролью `admin`.

## Следующий этап

Слой `data.js` сейчас содержит небольшой локальный набор для предпросмотра. Его нужно заменить Firebase-адаптером: Firebase Authentication для доступа операторов и участников, Firestore для коллекций `guests`, `rooms`, `payments`, `children`, `messages`, Storage для квитанций.
